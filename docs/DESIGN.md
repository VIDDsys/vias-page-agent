# Vias 页面助手界面规范

适用版本：0.15.0。覆盖侧栏 `sidepanel.html` 与设置页 `options.html`。

## 设计目标

这是帮助用户阅读与操作网页的工具界面。视觉要安静、清楚、可预期，优先让用户分辨当前模型、工作模式、任务内容与执行结果。保留 Vias 标识、模型配置、快捷指令、工具记录、提示词和赞助者信息。

两个页面各有明确取向：

- **侧栏**是任务工作区，使用石墨/中性灰的黑白灰体系，强调当前模式、工具记录与输入区；选中与成功不使用彩色强调。
- **设置页**与 VIDDsys 网站保持一致：白底、黑字、灰阶分隔线、单列纵向布局，尽量用正文、留白和标题层级说明信息，不堆小号说明文字。

两页都使用原生 HTML、CSS 和现有前端脚本，不引入组件框架、外部字体、CDN 或额外图片依赖。它是自定义工具界面，不冒充 Fluent、Carbon 等官方组件实现。

## 布局规则

**侧栏**

- 顶部放品牌、新建与设置入口，模型选择与问答/执行模式独立一行。
- 对话占用剩余高度并独立滚动。用户任务使用浅色表面，助手正文保持平直排版；工具记录按发生顺序插入，在原位置更新结果。
- 输入区固定在布局底部，四个快捷指令独立排列，发送和停止使用文字按钮。
- 不在任何系统状态条、工具标题或设置项中展示内部执行轮次。操作数量、图片编号、页面分段编号仍表达真实任务信息。
- 系统按内部计数限制执行，界面不提供轮数设置。达到上限时只说明任务停止及需要检查的状态。

**设置页**

- 顶部固定 52px 品牌栏，主内容宽度上限 960px，桌面左右至少 24px 外边距。
- 页面只有一个主标题「设置」，随后按「模型」「提示词」「赞助者」三段纵向排列，段间用 1px 分隔线和 48px 间距。
- 每段只有标题与内容，不再放重复的分区说明小字；必要说明放在对应控件下方，使用 14px 正文色。
- 模型列表放在一个与提示词输入框一致的圆角框内，行间用细线分隔，不逐行套卡片；当前使用只用文字标记，不用整行背景。次要操作（编辑、测试、删除）用文字按钮，只有「使用」保留实心主按钮。
- 编辑模型展开为独立面板，字段在宽屏两列、窄屏单列。

采用系统字体是本项目的明确决定：面向 Windows/Edge，保证中文可读、加载稳定，并避免扩展新增远程资源。设置页的字体顺序直接对齐网站 token。

字号阶梯：

- 侧栏：12px 辅助文字，13px 控件与元信息，14px 正文，16px 分区标题，17px 品牌，18px 空态与 Markdown 二级标题，22px 页面主标题与 Markdown 一级标题。最大 22px。
- 设置页：14px 标签、按钮与辅助说明，15px 正文与输入，16px 模型名称，18px 分区标题，20px 品牌，26px 页面主标题。最小 14px，不使用 12-13px 文字。

侧栏正文行高 1.65，助手内容行高 1.8；设置页正文行高 1.65。

## 交互与状态

- 可点击目标至少 44px 高，主入口保留文字。键盘焦点在设置页使用网站口径的 2px 石墨色描边；侧栏使用深色边框或控件内侧细线，不使用青色、绿色或套在外面的彩色光环。
- 设置页外框 1px，侧栏外框 1.5px；边框加深靠中性色，不靠彩色描边。
- 模型名称过长时省略，完整名称保留在提示或菜单中；菜单支持方向键、Home、End、Escape 和焦点归还。
- 发送、运行、停止、失败、取消和未确认结果都使用已有真实状态，不增加假的在线、已验证或百分比进度。
- 复制反馈只使用短暂文字提示。不做无意义入场、漂浮或脉冲动画；减弱动效偏好关闭剩余过渡。
- 错误保留具体原因与可执行的下一步。设置页的提示词冲突、保存中草稿和密钥显隐继续遵循现有状态逻辑。
- 保留扩展 CSP 和外置脚本，不将演示数据、模拟接口或内联事件处理器写入产品页面。

## 文案

- 设置页不写分区说明小字。页面主标题下只保留一句全局说明。
- 字段标签使用名词，不在括号里塞解释；必要限制放到控件下方的 14px 说明。
- 按钮用动词开头，不加感叹号；完成态用「已保存」这类直接表述。

## 验收

至少检查侧栏 320px、360px、390px，以及设置页 320px、390px、768px、1280px；覆盖浅色、深色、空态、长名称、错误态、工具时间线、模型编辑及提示词冲突。通过渲染后实测确认正文对比度、触控尺寸、边距、无意的横向溢出和真实点击命中。

执行 `design-lint.mjs` 对照本文件的色板、字体与间距检查，并结合截图复查；自动扫描不能替代真实交互与视觉审查。项目自动化测试使用隔离 Edge 和本地模拟接口，不代替所有业务网站验证。
