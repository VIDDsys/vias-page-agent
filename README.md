# Vias 页面助手

Edge 侧边栏网页操作 Agent（Manifest V3）。它读取当前页面，把页面快照交给你配置的 OpenAI 兼容模型，由模型执行点击、填写、选择、提交、滚动、导航等操作，可用于做题、填表、页面自动化。

## 安装

1. 从 [Release](https://github.com/VIDDsys/vias-page-agent/releases) 下载 zip，解压到一个固定目录（删除该目录扩展即失效）。
2. Edge 打开 `edge://extensions`，开启「开发人员模式」，点「加载解压缩的扩展」，选中解压出的文件夹。
3. 打开侧边栏，点右上角「设置」。首次使用已预置并选中「VIDDsys API」（地址 `https://api.viddsys.xyz/v1`，模型 `deepseek-v4.1-flash`），点击「填写密钥」，只填入自己的 API Key 后保存即可。也可点「添加模型」配置其它 OpenAI 兼容接口；已有配置会保留，预置提供商可编辑或删除。

在任意网页打开侧边栏：「执行」自动操作页面，「问答」只读不改页面。修改源码后需在扩展管理页点「重新加载」。设置页的自定义提示词在保存后从下一次任务生效；进行中的任务保留启动时版本，未保存草稿不会生效。留空保存可恢复默认：简洁回答，填表只写字段要求的必要内容。

侧栏顶部集中模型和工作模式，底部保留快捷指令与输入区；对话和工具结果按实际发生顺序显示，不展示内部轮次。设置页沿用站点的黑白灰单列布局，按模型、系统提示词与赞助者分区，减少辅助小字。两页都使用克制的小圆角，跟随系统浅色或深色主题。

## 模型与隐私

- 支持任意 OpenAI Chat Completions 兼容接口；API Key 只存在本地 `chrome.storage.local`，不上云同步。
- 页面文字会发送给你配置的 API。模型配置中的「模型支持图片输入」只标记接口能力；图片默认不附带。模型应优先使用正文与图片描述，仅在任务缺少必要视觉信息时选择图片，并说明具体读取原因；缺少原因不会读取。同一快照、同一图片、同一观察点的成功读取会去重。问答和执行均支持，不逐次询问或弹出授权。不会自动发送可见页面截图。
- 模型请求由侧边栏发起，规避 MV3 Service Worker 的 30 秒 fetch 限制。

## 工作机制

- **快照定位**：每次提取生成新的 `snapshotId`；同一文档内 ref 单调递增，避免续读后旧编号碰巧指向新目标。模型只能操作当前快照中已读分段的目标，同一快照继续读取不会让先前已读 ref 失效。页面跳转或目标身份变化时拒绝旧操作，无关页面更新不影响有效目标。答题选项的状态提示、焦点变化与等价重绘按稳定题目和选项身份复核；确认同题同值后继续，题干或选项值变化则拒绝。支持原生控件、ARIA 控件、富文本、列表项和 open Shadow DOM；敏感字段依据类型、属性及关联标签脱敏。
- **长页面与上下文**：初次及操作后读取统一默认每段 32,000 个 UTF-16 代码单元，单次冻结窗口最多 512,000 个代码单元或 30,000 个节点；达到上限明确标记，模型可继续读取后续窗口。同一快照已读原文去重保留至 64,000 个代码单元，超预算或切换窗口前由模型提供最多 12,000 个代码单元的累计阅读摘要，并明确哪些原文已省略。读取和续读每个任务最多 80 次；页面变化会拒绝不可靠的续接。上述字符数不是模型 token 数，也不代表服务商的上下文额度。
- **按需图片**：先提供 `img`、`canvas` 及 open Shadow DOM 图片的编号、尺寸、描述和视口信息，不主动读取像素。模型每次可选 1–3 张，每个任务最多 8 次请求；优先读取已加载内容，必要时仅下载所选的 HTTP(S) 图片，跨域下载不附带登录凭据。图片有来源前后校验、数量、体积、像素与时间限制，失败会明确返回。图片只进入下一次模型请求，之后的历史只保留文字摘要。
- **操作幂等**：同一 `operationId` 只执行一次；`check` 不会反选已勾选项；`fill` 相同值不重复触发事件；`repeat` 禁止嵌套，可随时取消。
- **任务隔离**：任务启动时绑定目标标签页，切换标签或窗口不会把后续读取、填写和点击转到当前活动页。任务自身导航仍在该标签内继续；打开新标签时，用 `webNavigation` 的导航来源核实后跟随，来源不匹配的页面不会接管。关闭任务页、关闭侧栏或连接断开会停止任务。每个任务独立 `runId`，停止即取消在途请求和页面等待；相同操作连续三次页面无进展、交替操作连续四次无变化、连续三轮零成功/通信失败或无效参数时自动停止，正常推进的执行任务默认最多 100 轮；内部计数不在界面显示。
- **模型协议**：只接受最终回答，不执行推理草稿或截断输出。执行指令只接受整条回复唯一的完整 JSON 对象或唯一闭合 JSON 代码块；夹带说明、多个候选对象、DSML 等模型内部调用标记（含单双全角竖线、Unicode 转义变体）或损坏协议会进入最多三次的纠正流程，不执行、不直接显示或保存原文，避免把示例代码当成实际操作。合法填写值中的特殊字符保持原义；问答模式仍可正常展示 JSON 和代码示例。历史助手消息中的内部调用标记会被过滤，用户原文保留。已失效的页面全文和图片不在后续请求中重复保留，操作历史使用有界摘要。
- **执行记录同步**：同一对话中开始新任务时，侧栏会把上一任务的实际动作与结果（含失败原因，最多 1,500 字符）作为模型上下文发送，模型据此判断页面是否已发生部分变更，不必等用户复述。该记录不进入聊天正文，新建对话时清空。
- **工具时间线**：点击、填写与图片 `image analyze` 按实际发出顺序显示，工具结果在原位置更新；同轮多次调用使用独立操作 ID，避免更新到其它工具行。停止或连接中断会结算仍在等待的工具状态。
- **长输入与请求时限**：单次提问、单字段值和操作说明各支持 200,000 个 UTF-16 代码单元；单批已解码文本总量 400,000，选择器最长 1,000。JSON 指令信封最多 3,000,000 个代码单元，覆盖合法转义的额外开销；普通问答正文最多 1,000,000，HTTP 响应读取最多 32 MiB。超限明确拒绝并提示拆分，不静默截短实际输入。历史保留完整条目，按数量、上下文或约 8 MiB 存储预算淘汰旧内容并提示；会话配额不足时明确报告，不删除其它窗口历史。字符限制不是模型 token 限制，也不能绕过网站字段自身约束。每次模型调用总时限 180 秒，重试共享剩余时间，后台另留 15 秒协调；快速失败最多普通重试两次，停止会取消在途请求。
- **填写确认**：填写、逐字输入和选择后核对页面稳定下来的实际结果；网站截短、回退或拒绝值时返回失败并停止同批后续提交。原生字段正常规范化仍可接受。输入框 Enter 按浏览器隐式提交规则保留默认提交按钮及其字段，禁用按钮或页面阻止提交时不强制提交。
- **完成与恢复**：`done:true` 表示模型结束任务；若最近仍有未确认的操作失败、通信不确定或部分执行，任务显示为未确认，不直接按成功结束。失败按目标身份和操作意图逐项记录，只有对应操作获得明确成功证据后才解除；无关目标的成功、`wait` 或 `NO_CHANGE` 不会抹去失败。重复操作保留有界的逐项进度与累计计数，帮助模型从失败处恢复；延迟打开的新标签被跟随后，旧页模型回复会被丢弃，重新读取新页再继续。
- **执行模式**：所有操作自动执行、不弹确认，请只在自己负责的页面和账号上使用。

## 验证

以下命令在源码仓库执行。桌面分发副本不包含 `tests/`、`docs/` 或开发依赖，用于直接加载扩展。

```bash
npm run check
npm test
# 安装 package.json 中的开发依赖并使用系统 Edge：
npm run test:all
```

`test:all` 覆盖语法、模型协议与特殊字符、请求预算与取消、长页面分段、任务循环、按需图片与跨域下载、内容脚本、真实扩展加载、代理集成、敏感字段和侧栏/设置页的错误及并发反馈。浏览器测试使用临时隔离配置及本地假模型，不读取日常浏览器配置，不调用付费接口。

界面颜色、字体、间距与圆角规范见 [docs/DESIGN.md](docs/DESIGN.md)；目标变化、延迟翻译与“未确认”判定等执行边界见 [docs/RELIABILITY.md](docs/RELIABILITY.md)。

## 已知边界

- 自动翻译或文字改写扩展可能延迟改变题干、选项和按钮文字。自动操作前请暂停这些扩展，或等翻译完成后再开始任务。「目标变化」表示旧目标需要重读，不必然表示此前没有发生点击；重试前应核对页面状态。
- 浏览器内部页面、扩展商店不可读取；iframe 内部内容（包括同源 iframe）和 closed Shadow DOM 暂不可深入。快照会标记 iframe；未加载或虚拟化的内容仍需页面自身加载后再读取。
- 文件上传、拖拽暂不支持；部分网站只接受真实物理输入（`isTrusted=true` 无法伪造）。按键仅在已实现的原生字段行为或可观察到控件实际响应时报告成功；无法可靠模拟或没有生效时会明确失败，可改用点击、填写或手动操作。
- 原生 `confirm`/`alert` 弹窗需手动处理；自动化测试不能代替目标网站实测。
